# DCIT 26 To-Do List

A React + Vite task management web app for the DCIT 26 laboratory activity.

## Features
- Dashboard with task totals
- Task group management
- Per-group task tracking
- LocalStorage persistence
- Responsive UI with Tailwind CSS
- Vercel-ready configuration

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
